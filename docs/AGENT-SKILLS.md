# Agent/design skill references

These are the requested external references. They are intentionally not copied into the application source; keeping them external avoids vendoring third-party content and licenses.

## Design / component references

- `DavidHDev/react-bits` — React animation/component inspiration.
- `emilkowalski/skills` — interaction, animation, mobile-native and UI review guidance.
- `yetone/kill-ai-slop` — visual anti-pattern checklist.

## Writing / documentation references

- `BolajiAyodeji/awesome-technical-writing`
- `conorbronsdon/avoid-ai-writing`

## Optional local agent installation

If you use an Agent Skills-compatible coding agent, install the requested skill repositories through that agent's own skill installer. For example:

```bash
npx skills@latest add emilkowalski/skills
npx skills@latest add yetone/kill-ai-slop
```

React Bits itself is primarily a copy/paste React component library rather than an application dependency, so this project does not install the whole library.
