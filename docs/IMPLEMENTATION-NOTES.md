# Reference and design notes

The project was designed with the requested repositories in mind:

- React Bits: component creativity and restrained motion; components remain copy/paste style rather than adding the entire library as a dependency.
- Emil Kowalski skills: motion should be purposeful, short, and reduced automatically for users who prefer reduced motion.
- Kill AI Slop: avoid indigo gradients, excessive glass effects, emoji-heavy UI, oversized metric cards, and decorative noise.
- Avoid AI Writing / technical-writing references: README and docs use direct, operational instructions.

The UI direction also borrows principles from Material Design 3 and shadcn-style primitives while keeping the visual language editorial: paper/ink surfaces, hairline borders, restrained accents, strong spacing and mobile-first information density.

For commercial deployment, verify the license terms of every external asset or component you copy. This project itself uses open-source package dependencies but does not bundle third-party repository code.
